4. App Submission Policy

Last Updated: November 2026

Technical Requirements

  • All downloadable builds (Android .apk, Windows .exe/.msi/.zip, Apple .dmg/.ipa/.zip) and Web URLs must be hosted over a secure HTTPS URL (such as GitHub Releases).
  • Browser-based SHA-256 verification supports up to 250MB for Android APKs and up to 500MB for Windows and Apple builds. Developers are strongly encouraged to generate the SHA-256 Integrity Checksum in the submission form so users can verify file authenticity.

  • Trojans, spyware, adware, rootkits, or hidden background crypto-miners.
